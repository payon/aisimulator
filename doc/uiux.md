## 10. PWA UI 컴포넌트

### 10.1 PWAInstallBanner (설치 프롬프트 배너)

```
┌─────────────────────────────────────────────────────────┐
│ 📱 이 앱을 설치하시겠습니까?     [설치] [✕ 닫기]     │
└─────────────────────────────────────────────────────────┘

| 속성 | 값 |
|------|-----|
| 위치 | 화면 하단 고정 (fixed bottom) |

| 숨김 | 사용자가 닫기 클릭 또는 이미 설치됨 |

| 컴포넌트 | PWAInstallBanner |

### 10.2 OfflineIndicator (오프라인 상태 표시)

```

┌────────────────────────────────────────────────────┐

|------|-----|

## 11. PWA 관련 UI 패턴

### 11.1 설치 프롬프트 흐름

```
beforeinstallprompt 발생
    ↓
PWAInstallBanner 표시 (하단)
    ↓
[설치] 클릭 → prompt() 호출
    ↓
설치 완료 → 배너 숨김, 축하 토스트
    ↓
앱이 standalone 모드로 실행
```

### 11.2 오프라인/온라인 전환 흐름

```
offline 이벤트 → OfflineIndicator 표시 (상단, 앰버)
    ↓
사용자 계속 사용 (캐시된 콘텐츠)
    ↓
online 이벤트 → OfflineIndicator "연결 복구" (에메랄드)
    ↓
3초 후 자동 숨김
    ↓
백그라운드 동기화 대기 중인 작업 자동 전송
```

### 11.3 푸시 알림 흐름

```
사용자가 알림 켬
    ↓
Notification.requestPermission()
    ↓
granted → PushSubscription 생성
    ↓
POST /api/pwa/subscribe (구독 등록)
    ↓
관리자가 POST /api/pwa/notify 발송
    ↓
Service Worker push 이벤트 → showNotification()
    ↓
사용자 클릭 → 앱 포그라운드로 열기
```
