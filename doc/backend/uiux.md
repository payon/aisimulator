# UI/UX Design for Senior Users (시니어 사용자 UI/UX 설계)

> 본 문서는 시니어 사용자를 위한 UI/UX 설계 지침을 정의합니다.
> 설계 원칙, 접근성 기능, 반응형 브레이크포인트, 컴포넌트 설계, 색상 체계, 타이포그래피, 간격 체계를 포함합니다.

---

## 1. Design Principles for Seniors (시니어 설계 원칙)

### 1.1 핵심 원칙

| 원칙 | 설명 | 적용 예시 |
|------|------|-----------|
| **큰 텍스트** | 모든 텍스트는 기본 18px 이상, 본문 20px | h1: 32px, 본문: 20px, 캡션: 16px |
| **고대비** | 명암비 4.5:1 이상 (일반), 7:1 (고대비 모드) | 검정 배경 + 흰 글자 |
| **단순 탐색** | 3단계 이내로 모든 기능 접근 가능 | 탭 → 목록 → 상세 |
| **명확한 피드백** | 모든 상호작용에 즉각적 시각+음성 피드백 | 버튼 클릭 → 색 변경 + TTS "선택됨" |
| **오류 방지** | 되돌릴 수 없는 행위는 확인 다이얼로그 | 삭제 전 "정말 삭제하시겠습니까?" |
| **일관성** | 동일 기능은 동일 UI 패턴 | 모든 목록: 카드 + 제목 + 요약 + 날짜 |

### 1.2 시니어 친화적 설계 가이드라인

```
┌─────────────────────────────────────────────────┐
│           Senior-First Design Guidelines          │
├─────────────────────────────────────────────────┤
│ 1. 한 화면에 하나의 주요 작업만                    │
│ 2. 모든 클릭 타겟은 48px 이상 (권장 64px)        │
│ 3. 텍스트 줄 간격은 글자 크기의 1.5배 이상         │
│ 4. 색상만으로 정보 전달 금지 (아이콘+텍스트 병행)  │
│ 5. 애니메이션은 최소화 (reducedMotion 존중)       │
│ 6. 시간 제한 없음 (또는 충분한 여유)              │
│ 7. 음성 안내 옵션 항상 제공                       │
│ 8. "도움말" 버튼 모든 화면에서 접근 가능           │
└─────────────────────────────────────────────────┘
```

## 2. Accessibility Features (접근성 기능)

### 2.1 폰트 스케일링 (Font Scaling)

| 단계 | 기본 배율 | 본문 크기 | 제목 크기 | 터치 타겟 |
|------|-----------|-----------|-----------|-----------|
| 보통 (normal) | 1.0x | 16px | 28px | 44px |
| 크게 (large) | 1.25x | 20px | 35px | 52px |
| 더 크게 (xlarge) | 1.5x | 24px | 42px | 56px |
| 매우 크게 (xxlarge) | 1.75x | 28px | 49px | 64px |

```typescript
// 폰트 스케일 적용
const FONT_SCALE_MAP = {
  normal:  1.0,
  large:   1.25,
  xlarge:  1.5,
  xxlarge: 1.75,
};

// Tailwind 동적 클래스 적용
function getScaledTextClass(baseSize: number, scale: number): string {
  const scaledSize = Math.round(baseSize * scale);
  return `text-[${scaledSize}px] leading-relaxed`;
}
```

### 2.2 고대비 모드 (High Contrast Mode)

| 모드 | 배경 | 전경 | 강조 | 대비비 |
|------|------|------|------|--------|
| 일반 (Light) | #FFFFFF | #1A1A2E | #E63946 | 14.7:1 |
| 일반 (Dark) | #1A1A2E | #F1FAEE | #E63946 | 13.8:1 |
| 고대비 | #000000 | #FFFFFF | #FFFF00 | 21:1 |

```css
/* 고대비 모드 CSS 변수 */
:root {
  --bg-primary: #FFFFFF;
  --text-primary: #1A1A2E;
  --color-accent: #E63946;
}

[data-high-contrast="true"] {
  --bg-primary: #000000;
  --text-primary: #FFFFFF;
  --color-accent: #FFFF00;
  --border-color: #FFFFFF;
}
```

### 2.3 음성 낭독 (TTS — Text-to-Speech)

```typescript
// 시니어 특화 TTS 설정
const SENIOR_TTS_CONFIG = {
  rate: 0.8,             // 기본 속도보다 느리게 (1.0 = 정상)
  pitch: 1.0,            // 기본 피치
  volume: 1.0,           // 최대 음량
  lang: 'ko-KR',         // 한국어
  autoRead: true,        // AI 응답 자동 낭독
  highlight: true,       // 낭독 중 텍스트 하이라이트
};

// 낭독이 필요한 UI 요소
const TTS_ENABLED_ELEMENTS = [
  'button',              // 버튼 레이블
  'nav-item',            // 탐색 항목
  'notification',        // 알림 메시지
  'chat-response',       // AI 응답
  'error-message',       // 오류 메시지
  'form-label',          // 폼 레이블
];
```

### 2.4 음성 입력 (STT — Voice Input)

```typescript
// 음성 입력 설정
const VOICE_INPUT_CONFIG = {
  language: 'ko-KR',
  continuous: false,       // 단발 인식 모드 (시니어 친화적)
  interimResults: true,    // 실시간 결과 표시
  visualFeedback: true,    // 녹음 중 시각적 표시 (파형)
  confirmationStep: true,  // 인식 결과 확인 단계
};

// 음성 입력 UI 흐름
// 1. 마이크 버튼 탭 → "말씀해 주세요" 안내 (TTS)
// 2. 말하는 동안 파형 애니메이션 + 인식 중인 텍스트 표시
// 3. 인식 완료 → 결과 텍스트 표시 + "이 내용이 맞나요?" 확인
// 4. 확인 → 텍스트 입력 필드에 삽입
// 5. 수정 필요 → 수동 편집 가능
```

### 2.5 대형 터치 타겟 (48px+)

```css
/* 최소 터치 타겟 규칙 */
.senior-button {
  min-height: 48px;          /* WCAG 최소 */
  min-width: 48px;
  padding: 12px 24px;        /* 충분한 패딩 */
}

.senior-button-lg {
  min-height: 56px;          /* 권장 크기 */
  min-width: 56px;
  padding: 14px 28px;
}

.senior-button-xl {
  min-height: 64px;          /* 키오스크/시니어 특화 */
  min-width: 64px;
  padding: 16px 32px;
}

/* 인접 터치 타겟 간격 */
.touch-target-group > * + * {
  margin-left: 12px;         /* 최소 8px, 시니어 12px */
}
```

### 2.6 온보딩 가이드 (Onboarding Guide)

```
온보딩 흐름 (최초 접속 시):

Step 1: 환영 화면
  → "안녕하세요! 복지 서비스에 오신 것을 환영합니다."
  → 음성 안내 자동 재생
  → [시작하기] 대형 버튼

Step 2: 폰트 크기 선택
  → "글자 크기를 선택해 주세요."
  → 미리보기 텍스트와 함께 4가지 크기 옵션
  → [이전] [다음]

Step 3: 음성 안내 설정
  → "음성 안내를 사용하시겠습니까?"
  → TTS 데모 재생
  → [네] [아니오]

Step 4: 주요 기능 안내
  → "복지 정보, 건강 정보, AI 상담사를 이용할 수 있습니다."
  → 각 기능 아이콘 + 설명 + 음성
  → [시작하기]

Step 5: 완료
  → "모든 준비가 끝났습니다! 시작해 볼까요?"
  → [시작하기] → 대시보드 이동
```

## 7. Spacing System (간격 체계)

### 7.1 간격 토큰 (4px 기본 단위)

| 토큰 | 크기 | 용도 |
|------|------|------|
| `space-0` | 0px | 없음 |
| `space-1` | 4px | 인라인 요소 간격 |
| `space-2` | 8px | 밀접한 요소 간격 |
| `space-3` | 12px | 관련 요소 간격 |
| `space-4` | 16px | 카드 간격 |
| `space-5` | 20px | 섹션 내 간격 |
| `space-6` | 24px | 카드 패딩 |
| `space-8` | 32px | 섹션 간격 |
| `space-10` | 40px | 큰 섹션 간격 |
| `space-12` | 48px | 페이지 섹션 간격 |
| `space-16` | 64px | 주요 구분 |

### 7.2 시니어 특화 간격 확대

```css
/* 시니어 모드: 간격 1.5배 확대 */
[data-senior-mode="true"] {
  --space-unit: 6px;   /* 기본 4px → 6px */
}

/* 키오스크 모드: 간격 2배 확대 */
[data-kiosk="true"] {
  --space-unit: 8px;   /* 기본 4px → 8px */
}
```

### 7.3 레이아웃 간격 규칙

```
컴포넌트 내부 패딩:
  - 소형 컴포넌트 (뱃지, 태그): space-2 (8px)
  - 중형 컴포넌트 (버튼, 입력): space-3 ~ space-4 (12-16px)
  - 대형 컴포넌트 (카드, 패널): space-6 (24px)

컴포넌트 간격:
  - 동일 레벨 요소: space-4 (16px)
  - 섹션 구분: space-8 (32px)
  - 페이지 구분: space-12 (48px)
```

## 9. Hydration 안전성 UI 패턴

### 9.1 SSR/CSR 전환 시 깜박임 방지

```typescript
// Hydration 안전 패턴
function Component() {
  const isHydrated = useHydrated();
  const isOnline = useClientValue(true, () => navigator.onLine);

  return (
    <>
      {/* SSR에서는 렌더하지 않음 */}
      {isHydrated && !isOnline && <OfflineIndicator />}
    </>
  );
}
```

| 컴포넌트 | SSR 렌더 | CSR 렌더 | 설명 |
|----------|----------|----------|------|
| OfflineIndicator | 숨김 | 오프라인 시 표시 | useClientValue(true, () => navigator.onLine) |
| PWAInstallBanner | 숨김 | 설치 가능 시 표시 | useClientValue(false, () => isInstallable) |
| PWANotificationManager | 숨김 | 권한 요청 표시 | useClientValue 적용 |
