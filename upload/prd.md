# PRD: AI 교육 시뮬레이션 프로그램 "AI 배움터"

## 1. 제품 개요
### 1.1 제품명
AI 배움터 (AI Learning Hub)

### 1.2 목적
시니어(60대 이상)를 포함한 전 연령대가 AI 기술을 체험하고 학습할 수 있는 크로스플랫폼 교육 시뮬레이션 프로그램

### 1.3 타겟 플랫폼
- 웹 브라우저 (Chrome, Safari, Edge, Firefox)
- 모바일 (Android, iOS)
- 데스크톱 (Windows, macOS, Linux)
- PWA (Progressive Web App) 설치 지원

### 1.4 타겟 사용자
| 구분 | 특징 |
|------|------|
| 시니어 | 디지털 기기 사용 미숙, 큰 글씨/버튼 필요 |
| 중장년층 | 기본 디지털 리터러시 보유 |
| 일반 사용자 | AI에 관심 있는 성인 |

## 2. 기능 요구사항

### 2.1 핵심 기능 (MVP)
1. **AI 채팅 체험**
   - 텍스트 입력 및 음성 입력
   - AI의 답변을 쉽게 이해할 수 있는 형태
   - 대화 기록 저장/불러오기

2. **AI 이미지 변환**
   - 사진 업로드 → AI 스타일 변환
   - 필터 선택 (유화, 수채화, 만화, 빈티지 등)
   - 변환 결과 다운로드

3. **미래의 나의 모습**
   - 현재 사진 업로드 → 나이 변환
   - 다양한 나이대 예측 (50대~80대)
   - 건강 관리 팁 제공

4. **AI 퀴즈 풀기**
   - AI 관련 기초 퀴즈
   - 난이도 조절 (입문/중급/고급)
   - 학습 진도 표시

5. **프롬프트 배우기**
   - 프롬프트 기본 개념
   - 단계별 실습
   - 좋은 프롬프트 vs 나쁜 프롬프트 비교

### 2.2 부가 기능
- AI 윤리 테스트
- AI 기술 구별하기 (실제 vs 생성)
- AI 안전 가이드
- 디지털 기기 탐지 교육

## 3. 비기능 요구사항

### 3.1 성능
- 페이지 로드 시간: 3초 이내
- 이미지 처리: 10초 이내 완료
- 동시 접속자: 1,000명 이상

### 3.2 접근성 (WCAG 2.1 AA 준수)
- 글씨 크기: 기본 18px 이상
- 명도 대비: 4.5:1 이상
- 키보드 네비게이션 완전 지원
- 스크린 리더 호환
- 고대비 모드

### 3.3 보안
- 사용자 데이터 암호화 (AES-256)
- 개인정보 90일 후 자동 삭제
- GDPR/개인정보보호법 준수
