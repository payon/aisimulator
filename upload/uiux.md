# UI/UX 디자인 가이드

## 1. 디자인 원칙

### 1.1 시니어 친화적 디자인 원칙
1. **인지 용이성**: 직관적인 아이콘과 명확한 레이블
2. **조작 용이성**: 큰 터치 타겟 (최소 48x48px)
3. **시각적 명확성**: 높은 명도 대비, 큰 글씨
4. **오류 방지**: 확인 단계, 되돌리기 기능
5. **친근함**: 따뜻한 색상, 격려하는 메시지

### 1.2 디자인 시스템

#### 색상 팔레트
Primary Colors:
AI Blue: #4A90D9 (신뢰, 기술)
Warm Orange: #FF8C42 (친근함, 따뜻함)
Fresh Green: #7BC67E (성장, 학습)
Neutral Colors:
Dark Text: #2D2D2D (가독성)
Light BG: #FAFAFA (눈의 피로 감소)
Card BG: #FFFFFF (구분)
Semantic Colors:
Success: #4CAF50
Warning: #FF9800
Error: #F44336
Info: #2196F3

4. 마이크로인터랙션
4.1 로딩 상태
시니어 친화적 로딩 애니메이션 (크고 명확한 프로그레스)
진행률 퍼센트 표시
예상 남은 시간 안내
4.2 피드백
성공: 초록색 체크 애니메이션 + "잘 하셨어요!" 메시지
오류: 빨간색 X + 명확한 해결 방법 안내
진행 중: 파란색 프로그레스 바 + 격려 메시지
4.3 네비게이션 피드백
활성 탭: 하단 강조선 + 색상 변경
뒤로가기: 슬라이드 애니메이션
페이지 전환: 페이드 인/아웃
5. 보이스 UI (VUI) 설계
명령어 체계:
  - "메인화면으로" → 홈 이동
  - "다음" → 다음 단계
  - "이전" → 이전 단계
  - "읽어줘" → TTS 실행
  - "멈춰" → 동작 중단
  - "도움말" → 가이드 표시
